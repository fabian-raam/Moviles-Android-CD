PROMPTS UTILIZADOS

Prompt 1 - DropdownMenu en productos

Agrega un menú de opciones con un ícono de tres puntos (⋮) en cada tarjeta de producto de una aplicación Android desarrollada con Jetpack Compose. Al presionar el menú debe aparecer un DropdownMenu con las opciones "Favoritos", "Compartir" y "Reportar". Cada opción debe tener su ícono correspondiente mediante leadingIcon.

Prompt 2 - Sistema de favoritos

Agrega una funcionalidad de favoritos a una aplicación Android desarrollada con Jetpack Compose. Cuando el usuario seleccione la opción "Favoritos" desde el DropdownMenu de una tarjeta de producto, el producto debe agregarse a una lista de favoritos. Si vuelve a seleccionar la opción, debe poder quitarse de favoritos.

Prompt 3 - NavigationDrawer con contador

Implementa un NavigationDrawer en Jetpack Compose con cuatro destinos: "Inicio", "Mis pedidos", "Favoritos" y "Perfil". El destino "Inicio" debe mantener la pantalla principal donde se pueden agregar y visualizar productos. El encabezado del Drawer debe mostrar información básica del usuario y el destino seleccionado debe quedar visualmente resaltado. Además, agrega un Badge dinámico en "Favoritos" que muestre la cantidad de productos marcados como favoritos.

Prompt 4 - Revisión de requisitos

Revisa la implementación completa de una aplicación Android con Jetpack Compose y verifica que cumpla los requisitos del laboratorio: cada tarjeta de producto debe tener un DropdownMenu con las opciones Favoritos, Compartir y Reportar con sus respectivos íconos; el NavigationDrawer debe contener Inicio, Mis pedidos, Favoritos y Perfil; Inicio debe mantener la funcionalidad para agregar productos; el encabezado del Drawer debe mostrar datos del usuario; el destino activo debe estar resaltado; y el Badge de Favoritos debe actualizarse automáticamente según la cantidad de productos favoritos.
